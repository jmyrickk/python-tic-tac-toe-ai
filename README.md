# Tic-Tac-Toe with AI 🎮

A desktop Tic-Tac-Toe game built with **Python** and **CustomTkinter**. The game includes an interactive graphical interface, score tracking, win detection, game reset functionality, and a rule-based AI opponent.

## Features

* 🎮 Interactive 3×3 game board
* 🤖 Rule-based AI opponent
* 🏆 Automatic win detection
* 📊 Player score tracking
* 🔄 Game reset functionality
* 🖥️ Graphical user interface built with CustomTkinter
* 🎯 Strategic AI decision-making

## AI Strategy

The AI uses a priority-based decision-making system:

1. Try to win if a winning move is available
2. Block the player's winning move
3. Take the center position
4. Choose an available corner
5. Choose one of the remaining side positions

This approach demonstrates basic AI logic, conditional decision-making, game-state analysis, and event-driven programming.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/tic-tac-toe-ai.git
```

2. Install the required dependency:

```bash
pip install customtkinter
```

3. Run the program:

```bash
python "tic tac toe with AI.py"
```

# Крестики-нолики с AI 🎮

Настольная игра «Крестики-нолики», разработанная на **Python** с использованием **CustomTkinter**. Игра включает интерактивный графический интерфейс, подсчет очков, определение победителя, возможность сброса игры и противника с алгоритмом принятия решений на основе правил.

## Возможности

* 🎮 Интерактивное игровое поле 3×3
* 🤖 Противник с алгоритмом принятия решений
* 🏆 Автоматическое определение победителя
* 📊 Подсчет очков игроков
* 🔄 Возможность сбросить игру
* 🖥️ Графический интерфейс на CustomTkinter
* 🎯 Стратегическое принятие решений AI

## Логика AI

AI использует систему принятия решений с определенным приоритетом:

1. Попытаться выиграть, если доступен победный ход
2. Заблокировать возможный победный ход игрока
3. Занять центральную клетку
4. Выбрать свободный угол
5. Выбрать одну из оставшихся боковых клеток

Такой подход демонстрирует базовую логику AI, использование условных конструкций, анализ состояния игры и событийное программирование.
